# Publication preparation

The corrected archive is a working research release. Complete author and public
repository metadata before publication; it is deliberately not invented here.
The manuscript states the remaining scientific limits. Do not replace those
limits with claims of calibrated real-material posteriors or independent causal
validation based only on the included synthetic tests.

For a new numerical release, rerun the workflow, regenerate the manuscript
numbers and figures, run tests and verification, and regenerate SHA256SUMS.
Keep the frozen observational data and their source attribution unchanged unless
the corpus itself is intentionally revised and documented. Training/checkpoint
versions and simulator versions must match.
