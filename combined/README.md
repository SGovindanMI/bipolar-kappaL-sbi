# Combined manuscript build

The main README is the authoritative workflow. Both internal stages, v5 and v6, are unpublished components of this same study.

Build order: `build_combined_numbers.py`, `make_combined_figures.py`, `npm run build` within this directory, then `python combined/finalize_documents.py` from the repository root. Finalisation produces 7 main figures, 2 main tables, 30 supplementary tables and 1 supplementary figure; all original analyses are retained. The abstract is shortened and references are ordered by first citation.

The numerical checker verifies traceability, not scientific meaning. `verify_family_comparison.py` recalculates paired and unpaired family intervals on common selected curves from the compact verification archive. `audit_final.py` checks the final Word/PDF artifacts and produces internal page images for visual inspection. DOCX equations remain editable; all raster artwork is 600 dpi with editable PDF/SVG versions. Final PDFs were exported from Word.

The reference checkpoint selected epoch 890 in one-based notation (stored zero-based index 889). Source physics and inference modules were not changed for this editorial revision; training/inference were not repeated. Large data arrays are a separate deposit, not part of the GitHub tree. See `FINAL_REVISION_REPORT.md` for scope and outstanding author/deposit information.

## Scientific audit of the combined draft

See `../MANUSCRIPT_AUDIT_REPORT.md` for the completed audit and remaining limitations. With the separate data archive restored, run `python combined/audit_scientific_claims.py` from the repository root for the 627 claim-specific checks. Common-family verification separately recomputes 60 interval triplets. Same-model and native upturn numbers now come directly from full-precision diagnostic JSON, not rounded Markdown. Main-text links cover every supplementary table; the Supplementary Information remains a separate companion document.

The component comparison in Supplementary Tables 28–30 is generated by `python combined/component_comparison.py` after restoring the large data archive. It uses each model’s own saved posterior summaries and reconstructs the 1,528-curve intersection. The committed `component_comparison.json` allows document builds without rerunning that calculation; `component_source_data.csv` supplies all 9,168 model/curve rows. The main manuscript explains the results in Section 3.10. No training or inference rerun is required.
